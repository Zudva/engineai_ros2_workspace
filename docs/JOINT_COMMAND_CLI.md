# Joint Command CLI (Расширенная Документация)

Скрипт: `scripts/joint_command_cli_test.sh`

Назначение: быстрые эксперименты с позами и движениями суставов без написания кода.
Поддерживает симуляцию и осторожные аппаратные проверки с системой ограничений (safety).

## Безопасность (Safety)
Активна по умолчанию:
- `MAX_ABS_LIMIT` — глобальный предел |q| (по умолчанию 0.2)
- `MAX_STEP_LIMIT` — максимум |Δq| за один тик (0.04)
- `RAMP_TIME` — плавный вход/выход волновых паттернов (0.5 c)
- `ARM_MAX_ABS_LIMIT` — (опционально) отдельный предел только для режимов рук
- `DISABLE_SAFETY=1` — отключить защиту (только диагностика, НЕ использовать долго на железе)
- `VERBOSE=1` — подробный пошаговый вывод

Алгоритм: каждое целевое значение проходит через `safety_adjust_array` → ограничение шага → ограничение амплитуды → обновление внутреннего состояния.

## Общий Формат
```
./scripts/joint_command_cli_test.sh <mode> [аргументы]
```

## Таблица Режимов
| Mode | Назначение | Аргументы (минимум → дополнительные) | Типичное применение |
|------|------------|---------------------------------------|--------------------|
| `zero` | Публикация нулевой позы | `[count]` | Сброс / стабилизация |
| `single` | Один сустав в фиксированном угле N шагов | `<joint> <angle> [rate=10] [duration=2]` | Проверка направления, оценка трения |
| `ramp` | Линейный переход 0→target | `<joint> <target> <duration> [rate=50]` | Плавная отладка отклика |
| `wave` | Синус на одном суставе | `<joint> <amp> <freq> <dur> [rate=50]` | Частотный отклик |
| `all_wave` | Одинаковая синусоида на всех | `<amp> <freq> <dur> [rate=50] [phase_step=0]` | Нагрузка питания (низкая амп.) |
| `travel_wave` | Бегущая фаза по массиву | `<amp> <freq> <dur> [rate=50] [periods=1]` | Проверка индексации |
| `multi_wave` | Сумма двух волн | `<amp1> <f1> <amp2> <f2> <dur> [rate=50] [phase_step=0]` | Резонансы (симуляция) |
| `cascade` | Последовательный запуск суставов | `<amp> <freq> <dur> [rate=40] [hold=0.2]` | Диагностика тока, ступенчатая нагрузка |
| `random_pose` | Полностью новая случайная поза каждый тик | `<amp> <dur> [rate=10]` | Стресс-тест (только сим) |
| `random_safe` | Ограниченный случайный прогулочный шум | `<amp> <dur> [rate=10] [max_step=0.05] [indices=all]` | Лёгкие возмущения (железо) |
| `arms_wave` | Синус на суставах рук | `<amp> <freq> <dur> [rate=50] [side=both] [per_joint_phase=0] [lr_phase=0]` | Симметрия / визуализация |
| `arms_raise` | S‑curve подъём одного сустава руки | `<side> <target> <dur> [rate=40] [joint_offset=2] [hold=0]` | Подъём плеча/локтя |
| `arms_scan` | Перебор offset 0..4 для руки | `<side> <target> [dur=1.5] [rate=20] [hold=0.3]` | Поиск нужного offset |
| `joint_scan` | Перебор диапазона индексов | `<angle> <hold> [rate=10] [start=0] [end=23]` | Карта всех суставов |

### Дополнения к аргументам
- `phase_step` — добавляет фазовый сдвиг i*phase_step между соседними суставами (diagonal / ripple)
- `periods` — сколько полных 2π фаз растянуть по всем суставам (`travel_wave`)
- `joint_offset` — локальный индекс в пятёрке сустава руки (0..4)
- `side` — `left|right|both`

## Примеры
```bash
# Скан индексов (диагностика; осторожно) — затем вернуть safety!
DISABLE_SAFETY=1 ./scripts/joint_command_cli_test.sh joint_scan 0.4 0.25 8 0 23

# Скан offset внутри левой руки для подъёма
./scripts/joint_command_cli_test.sh arms_scan left 0.6

# Подъём левой руки (offset 2) S‑curve + удержание 1 c
ARM_MAX_ABS_LIMIT=1.0 ./scripts/joint_command_cli_test.sh arms_raise left 0.9 3 40 2 1

# Лёгкий безопасный шум на трёх суставах
./scripts/joint_command_cli_test.sh random_safe 0.25 8 15 0.02 0,1,2

# Бегущая волна (1 полный период вдоль массива)
./scripts/joint_command_cli_test.sh travel_wave 0.15 0.6 6 50 1

# Две частоты (только симуляция)
./scripts/joint_command_cli_test.sh multi_wave 0.12 0.5 0.05 1.3 10 60 0.2
```

## Рекомендованный Порядок Настройки Руки (HW)
1. `joint_scan` для общей карты.
2. `arms_scan left 0.6` чтобы найти корректный `joint_offset`.
3. Тест знака направления: `single <index> 0.5` и затем `single <index> -0.5`.
4. Подъём S‑curve с малым углом (0.4), потом увеличивать.

## Типичные Проблемы и Решения
| Симптом | Причина | Решение |
|---------|---------|---------|
| Рывок только в начале | S‑curve мала на старте + клиппинг | Увеличить target постепенно / ослабить MAX_STEP_LIMIT до 0.06 |
| Амплитуда обрезана | Достигнут MAX_ABS_LIMIT | Повысить MAX_ABS_LIMIT или ARM_MAX_ABS_LIMIT |
| Рука не реагирует | Неверный offset или индекс | arms_scan / joint_scan повторить |
| Волну «рвёт» | Слишком мал шаг времени / высокая частота | Уменьшить freq или увеличить rate |
| Шум слишком быстрый | max_step велик | Понизить max_step / MAX_STEP_LIMIT |
| Перегрев / шум моторов | Большая амплитуда или без ramp | Снизить amp, добавить RAMP_TIME |

## Отладка
- `VERBOSE=1` печатает позиции.
- Логирование: `VERBOSE=1 ... > log.txt`.
- Сравнение реального движения с ожидаемым: `ros2 topic echo /hardware/joint_state` и анализ индексов.

## Расширения (Идеи)
- CSV лог (время, массив позиций)
- Сплайновые траектории (кубический / quintic)
- Автоматическое определение набора суставов руки по паттерну движения
- Интеграция с PlotJuggler (маркер режима)

## Best Practices (HW)
- Начинать с амплитуды ≤0.2 рад.
- Не отключать защиту дольше кратких диагностик.
- Повышать лимиты точечно (через ARM_MAX_ABS_LIMIT).
- Фиксировать найденные индексы в отдельной конфигурации.
